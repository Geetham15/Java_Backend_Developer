## 📌 Project 1: Employee Management System

**Technologies:** Java 21 | Spring Boot | Spring Data JPA | Hibernate | MySQL | REST APIs

A Spring Boot-based backend application designed to manage employee information through RESTful web services.

### Key Features

- Employee CRUD operations (Create, Read, Update, Delete)
- Spring Data JPA repository integration
- Hibernate ORM and MySQL database connectivity
- DTO implementation for request and response handling
- Bean Validation
- Global Exception Handling
- Custom repository queries
- Pagination and Sorting
- Slice-based data retrieval
- Dynamic filtering using Spring Data JPA Specifications
